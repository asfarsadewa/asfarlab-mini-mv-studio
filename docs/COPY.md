# Copy rules

Docs, UI labels, messages and credits follow the ASD-STE100 register. Lyrics, translations and text in an in-fiction voice are exempt. Code comments are exempt.

- Write one instruction or one topic per sentence.
- Use 20 words or fewer per sentence.
- Use active voice. Name the agent if one exists.
- Use the imperative for instructions. Use the present tense for descriptions.
- Use "if" for conditions and "when" for time. Do not use "unless".
- State the mechanic, not the mood.
- Use sentence case and as few words as possible.

Do not write:

- Contrast tails such as "X, not Y", "rather than" or "instead of Y". Write two sentences.
- Two claims joined by "and". Split them. A list of nouns is fine. One subject with two verbs is fine.
- Fragments as sentences.
- Aphorisms, rhythm for its own sake, punchlines, personified abstractions or contractions.

Scan the strings for these patterns before a commit.
